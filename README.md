## Installation

Follow these steps to set up the project locally:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/KennyD4Christ/Finstock.git

2   cd Finstock
Backend Setup:

Create a virtual environment and activate it:
python -m venv backend_env
source backend_env/bin/activate  # On Windows use `backend_env\Scripts\activate`

3 Install the required packages:
pip install -r requirements.txt

4 Apply migrations and start the server:
python manage.py migrate
python manage.py runserver

5 Frontend Setup:
Navigate to the frontend directory:
cd frontend

6 Install the required packages:
npm install webpack webpack-cli --save-dev  # Installs Webpack and its command-line interface for development
npm install react-router-dom --save  # Installs React Router DOM for web routing
npm install styled-components --save  # Installs Styled Components for CSS-in-JS styling
npm install axios --save  # Installs Axios for making HTTP requests

7 Start the development server:
npm start

Usage
Accessing the Application:

Open your browser and navigate to http://localhost:3000.
Login/Register:

Use the login page to sign in with your credentials or register a new account.
Managing Data:

Use the navigation menu to manage orders, customers, products, invoices, and transactions.
Generate and view reports to analyze your business performance.
